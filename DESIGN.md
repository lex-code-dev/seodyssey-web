# DESIGN.md — SEOdyssey

Единая дизайн-система для лендинга (seodyssey.ru) и приложения (app.seodyssey.ru).
Основа — стиль лендинга (тёплая бумага + перивинкль), приложение приводится к нему.
Реализация: лендинг — инлайн-стили в шаблонах landing/, приложение — `static/css/app.css` (+ Tailwind CDN c маппингом токенов).

## Theme

Светлая тема. Сцена: специалист днём за рабочим ноутбуком, много вкладок, быстрое сканирование статусов. Тёмная тема не используется.

Характер: дружелюбный проводник, живой и смелый. Метафора бренда — одиссея/маршрут (спираль в логотипе). Главный запрет — перегруженность.

## Color

Стратегия: Restrained в приложении, Committed на лендинге (перивинкль несёт бренд в hero и CTA).

### Tokens

| Token | Value | Role |
|---|---|---|
| `--bg` | `#F7F4EE` | фон страниц (тёплая бумага — committed identity лендинга) |
| `--surface` | `#FFFFFF` | карточки, панели, поля ввода |
| `--surface-2` | `#F1EDE5` | вторичные подложки, sidebar приложения |
| `--line` | `rgba(21,20,15,0.09)` | границы |
| `--line-strong` | `rgba(21,20,15,0.18)` | границы форм, hover |
| `--ink` | `#15140F` | основной текст, тёмные панели |
| `--ink-2` | `#3D3A33` | вторичный текст |
| `--muted` | `#6E695E` | подписи (контраст на --bg ≥ 4.5:1 — проверено) |
| `--accent` | `#6378FF` | перивинкль: действия, ссылки, выделение |
| `--accent-hover` | `#4F5BE0` | hover действий |
| `--accent-bg` | `#EEF0FF` | тонированные подложки акцента |
| `--accent-ink` | `#3D4CC4` | текст на `--accent-bg` (≥4.5:1) |
| `--ok` | `#1F7A3D` / bg `#E7F3E9` / dot `#28C840` | успех |
| `--warn` | `#8A5A00` / bg `#FBF0DA` / dot `#FEBC2E` | предупреждение |
| `--fail` | `#B3261E` / bg `#FDEEEC` / dot `#FF6058` | ошибка |
| `--code-bg` | `#121316` | код-блоки, тёмные фрагменты отчётов |

Правила:
- Акцент — только действия, ссылки, текущее состояние. Не декор.
- Статусы никогда не «только цветом»: рядом точка/иконка/текст.
- Серый текст на цветных подложках запрещён — использовать тёмный тон подложки (`--ok`/`--warn`/`--fail`, `--accent-ink`).

## Typography

| Role | Font | Notes |
|---|---|---|
| Display (h1–h2 лендинга, крупные цифры отчётов) | **Unbounded** 500–600 | кириллица-нативный, широкий, несёт «живой и смелый». Только крупные размеры (≥28px). Letter-spacing −0.01…−0.02em, не плотнее |
| UI / body | **Inter** 400–700 | committed identity, разрешён в product-регистре. Body 15–16px / 1.55 |
| Data / code | **JetBrains Mono** 400–500 | код-блоки, URL, метрики, timestamps. Уже часть идентичности (продукт продаёт «готовый код») |

- Заголовки h1–h3: `text-wrap: balance`. Прозa: max-width 65–75ch.
- Лендинг: fluid clamp() шкала, ratio ≥1.25. Hero h1 ≤ 60px.
- Приложение: фиксированная rem-шкала, ratio 1.2: 13 / 14 / 15 / 18 / 22 / 26px. Display-шрифт в UI-лейблах и кнопках запрещён.

## Spacing & Layout

- Базовая сетка 4px; приложение: контент max-w-6xl, страницы `px-6 py-8`.
- Лендинг: секции `clamp(56px, 7vw, 96px)` по вертикали, max-width 1200px.
- Карточки — только когда это лучший афорданс; вложенные карточки запрещены.
- Радиусы: 11–13px кнопки/поля, 14–18px крупные поверхности (уже в идентичности).

## Components (приложение)

- **Кнопки**: `.btn-primary` (accent), `.btn-ghost` (прозрачная с line), `.btn-danger`. Все состояния: hover, focus-visible (2px accent ring), disabled.
- **Бейджи статусов**: `.badge-ok/-warn/-fail` — тонированная подложка + тёмный текст того же тона + точка.
- **Sidebar**: `--surface-2`, активный пункт — `--accent-bg` + `--accent-ink`.
- **Таблицы/списки проверок**: плотность разрешена; zebra не нужна, разделители `--line`.
- **Пустые состояния**: обучающие — что сделать первым шагом, с одним CTA.
- **Загрузка**: skeleton, не спиннер в центре контента.

## Motion

- Приложение: 150–250ms, `ease-out`; только смена состояний. Без оркестровки загрузки.
- Лендинг: reveal-анимации уже есть (`data-reveal`) — сохранять паттерн; hover-подъёмы карточек ≤4px.
- `prefers-reduced-motion: reduce` обязателен (на лендинге реализован глобально — не ломать).

## Assets

- Логотип: `static/img/spiral-icon.svg` (спираль). 
- Фавикон: `staticfiles/core/favicon.*`.
- Иллюстрации не используются: «показывай, не рассказывай» — вместо картинок реальные фрагменты отчётов, код, статусы.

## Register overrides

- `landing/` (index, blog, geo-check, tools, offer): регистр **brand** — разрешены committed-цвет, крупная типографика, оркестрованный первый экран.
- `core/`, `ai_queries/`, `audits/`, `registration/`: регистр **product** — restrained, консистентность важнее сюрприза.
