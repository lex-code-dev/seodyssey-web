# Мета-теги

### Title

**Что это**
HTML-тег `<title>` в `<head>`. Рабочий ориентир длины — 50–60 символов, но смысл важнее слепого счётчика.

**Почему важно для SEO**
Важно для SEO, потому что влияет на один или несколько базовых блоков: индексацию, ранжирование, CTR, обход сайта, доверие, поведенческие сигналы или конверсию. Если этот элемент сломан на шаблоне, проблема масштабируется сразу на десятки или тысячи URL.

**Как диагностировать**
Screaming Frog → Page Titles; Яндекс.Вебмастер → Диагностика; GSC → Performance по URL.

**Как исправить**
1. Найдите все URL, где проблема повторяется.
2. Исправьте первопричину в шаблоне, CMS, коде или настройках.
3. Проверьте 3–5 типовых URL вручную и через краулер.
4. Отправьте важные страницы на переобход.

**Пример правильного варианта**
```
<title>Купить беговые кроссовки Nike в Москве — SportShop</title>
```

**Пример неправильного варианта**
```
<title>Кроссовки, купить кроссовки, кроссовки цена</title>
```

**Частые ошибки**
- Исправляют один URL вместо шаблона.
- Не проверяют результат после релиза.
- Проверяют только главную.
- Не фиксируют дату изменения.

1. Найдите все URL, где проблема повторяется.

### Шаблон мета-тегов для страницы контактов

**Что это**
Шаблон мета-тегов для страницы контактов — коммерческий фактор, который помогает пользователю понять, можно ли доверять сайту и удобно ли купить/заказать.

**Почему важно для SEO**
Важно для SEO, потому что влияет на один или несколько базовых блоков: индексацию, ранжирование, CTR, обход сайта, доверие, поведенческие сигналы или конверсию. Если этот элемент сломан на шаблоне, проблема масштабируется сразу на десятки или тысячи URL.

**Как диагностировать**
Проверьте шапку, футер, страницу услуги/товара, контакты, формы, цены, отзывы, документы и путь до заявки.

**Как исправить**
1. Найдите все URL, где проблема повторяется.
2. Исправьте первопричину в шаблоне, CMS, коде или настройках.
3. Проверьте 3–5 типовых URL вручную и через краулер.
4. Отправьте важные страницы на переобход.

**Пример правильного варианта**
```
На странице есть цена или диапазон, контакты, условия, доказательства доверия и рабочая форма.
```

**Пример неправильного варианта**
```
Нет цены, нет реквизитов, форма не работает, а телефон спрятан картинкой.
```

**Частые ошибки**
- Исправляют один URL вместо шаблона.
- Не проверяют результат после релиза.
- Проверяют только главную.
- Не фиксируют дату изменения.
