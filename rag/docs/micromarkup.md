# Микроразметка

### Schema.org

**Что это**
Словарь структурированных данных для описания сущностей страницы.

**Почему важно для SEO**
Важно для SEO, потому что влияет на один или несколько базовых блоков: индексацию, ранжирование, CTR, обход сайта, доверие, поведенческие сигналы или конверсию. Если этот элемент сломан на шаблоне, проблема масштабируется сразу на десятки или тысячи URL.

**Как диагностировать**
validator.schema.org; Google Rich Results Test.

**Как исправить**
1. Найдите все URL, где проблема повторяется.
2. Исправьте первопричину в шаблоне, CMS, коде или настройках.
3. Проверьте 3–5 типовых URL вручную и через краулер.
4. Отправьте важные страницы на переобход.

**Пример правильного варианта**
```
{"@context":"https://schema.org","@type":"Organization","name":"SEOdyssey"}
```

**Пример неправильного варианта**
```
{"@type":"Product","ratingValue":"5"} без отзывов на странице
```

**Частые ошибки**
- Исправляют один URL вместо шаблона.
- Не проверяют результат после релиза.
- Проверяют только главную.
- Не фиксируют дату изменения.

1. Найдите все URL, где проблема повторяется.

4. Отправьте важные страницы на переобход.

**Пример правильного варианта**
```
Название, адрес, телефон, график и сайт совпадают на сайте, в Яндекс.Бизнесе, Google и справочниках.
```

**Пример неправильного варианта**

Важно для SEO, потому что влияет на один или несколько базовых блоков: индексацию, ранжирование, CTR, обход сайта, доверие, поведенческие сигналы или конверсию. Если этот элемент сломан на шаблоне, проблема масштабируется сразу на десятки или тысячи URL.

**Как диагностировать**
Проверьте выборку важных URL: главную, категории, карточки, статьи, страницы услуг и контакты. Используйте Screaming Frog, Яндекс.Вебмастер, Google Search Console, браузер DevTools и ручную проверку.

**Как исправить**
1. Найдите все URL, где проблема повторяется.
2. Исправьте первопричину в шаблоне, CMS, коде или настройках.
3. Проверьте 3–5 типовых URL вручную и через краулер.
4. Отправьте важные страницы на переобход.

**Пример правильного варианта**
```
Проверка микроразметки: настроено корректно, данные совпадают на странице, в коде и в инструментах поисковиков.
```

**Пример неправильного варианта**
```
Проверка микроразметки: настройка есть формально, но ведёт на дубль, ошибку, устаревшие данные или не соответствует содержанию страницы.
```

**Частые ошибки**
- Исправляют один URL вместо шаблона.
- Не проверяют результат после релиза.
- Проверяют только главную.
- Не фиксируют дату изменения.
