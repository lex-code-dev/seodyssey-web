Источник: официальная документация Яндекса, актуально на 2025 год.

## 1. Вкладка «Диагностика сайта» → «Ошибки»

### 1.1 Главная страница сайта возвращает ошибку
- Страница закрыта от индексации (директива noindex)
- Со страницы настроен редирект
- Система безопасности хостинга блокирует робота Яндекса
- Страница возвращает код, отличный от 200 OK

### 1.2 Не удалось подключиться к серверу из-за ошибки DNS
- Некорректно настроены DNS-записи
- Кратковременная проблема с доступом к сайту
- Доменное имя не продлено вовремя

### 1.3 Сайт закрыт для индексирования в файле robots.txt
- Робот получил запрещающую директиву Disallow: /
- Доменное имя не продлено — регистратор переписал robots.txt
- Сайт доступен по HTTP и HTTPS, добавлен HTTP, но запрещены обе версии

### 1.4 Обнаружены нарушения или проблемы с безопасностью
- Подробности — в разделе «Безопасность и нарушения» (см. раздел 3)

### 1.5 Долгий ответ сервера
- Некоторые страницы загружаются больше 3 секунд
- Замедляет индексирование сайта

### 1.6 Некорректная настройка SSL-сертификата
- Истёк срок действия сертификата
- Сертификат выдан на другой домен или не на все поддомены
- Сертификат удостоверяющего центра отсутствует в браузерах или отозван
- Используется самоподписанный сертификат

### 1.7 Найдены страницы-дубли с GET-параметрами
- URL с GET-параметрами дублируют страницы без параметров
- Решение: директива Clean-param в robots.txt

## 4. Примечания по процессу исправления

- Ошибки проверяются роботом ежедневно
- После исправления: нажать «Я всё исправил» → дождаться переобхода
- Повторно сообщить об исправлении можно не раньше чем через 30 дней
- Для ускорения — отправить страницы на переобход вручную
- Переобход занимает до 2 недель
